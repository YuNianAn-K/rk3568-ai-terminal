# Board / Screen / Wi-Fi Checklist

- [ ] RK3568 能正常开机
- [ ] MIPI 屏亮屏
- [ ] 显示无明显异常
- [ ] 触摸有响应
- [ ] SSH 能连接
- [ ] Wi-Fi 能扫描
- [ ] Wi-Fi 能连接
- [ ] 获取到 IP
- [ ] 能 ping 网关
- [ ] 能 ping 公网 IP
- [ ] SystemUI 显示当前 SSID 与信号
- [ ] Settings 显示错误密码提示
- [ ] Settings 显示成功连接提示
- [ ] 重启后自动回连
- [ ] Qt 程序能启动
- [ ] Qt 界面能触摸
- [ ] 启动入口或命令已记录
- [ ] 问题现象已记录

详细操作、命令和记录表见 [Wi-Fi 板屏验收](../board-screen-wifi-acceptance.md)。Wi-Fi 密码不得写入此清单或任何日志。
