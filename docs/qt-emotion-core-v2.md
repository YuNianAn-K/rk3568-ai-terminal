## 六态变化

| 状态 | 可辨认的静态形态 | 动态增强 |
| --- | --- | --- |
| 待机 | 18×22 的放松圆眼 | 慢漂浮、呼吸、偶尔眨眼 |
| 聆听 | 25×34 的睁大眼睛，间距 60，球体基准放大 3.5% | 双环扩散更清晰，漂浮幅度缩小 |
| 思考 | 19×16 的眼睛，视线偏右 16、偏上 22，轻微倾斜 | 4 个更清晰的绕行光点，小幅斜上方视线活动 |
| 说话 | 34 宽的柔和弧眼 | 6% 全幅的有节奏脉动 |
| 离线 | 23×6 的半闭眼，暖色低亮度 | 更慢、更小幅的漂浮与呼吸 |
| 错误 | 27×8 的相向倾斜眼睛 | 每个新错误只收缩一次，之后安静等待重试 |

以上尺寸为 720×1280 基准画布坐标，实际板屏等比放大。颜色、呼吸和漂浮参数在 `UiTheme.qml`；眼睛、视线及基准缩放在 `EmotionCore.qml` 的 `poses` 中。

几何、视线、眼形和冷暖纹理使用 280 ms 统一过渡；先等待动画目标绑定更新再启动，防止快速状态切换读取上一态参数。进入后台、隐藏或诊断页时收尾过渡并停止活动动画；后台状态变化直接更新到当前静态形态。无嘴巴、动物特征、实时模糊、Canvas 绘制或新增着色器。

聆听光环、说话脉动和现有声波仍为装饰性活动指示，不是真实音量，也不分析回答内容的情感；未扩大语音事件接口。
