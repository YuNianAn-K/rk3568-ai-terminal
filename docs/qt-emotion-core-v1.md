## 可调整入口

| 文件 | 调整内容 |
| --- | --- |
| `UiTheme.qml` | 配色、光球直径、漂浮/呼吸节奏、错误提示时长 |
| `AppMainBody.qml` | 720×1280 画布布局、控制按钮和安全区 |
| `EmotionCore.qml` | 眼点、光环、4 个绕行光点、眨眼和单次错误效果 |
| `core-cool.svg` / `core-warm.svg` | 静态透明球体与柔光；不做实时滤镜 |
| `VoiceState.js` | 原始服务状态到六个视觉状态和按钮动作的映射 |
| `VoiceWave.qml` | 9 条活动指示，预留 `audioLevel` 输入 |

`initializing` 使用待机外观；`starting` 使用准备聆听外观但不启动声波；
`recognizing/thinking/replying` 使用思考外观；`playing` 使用说话外观。
录音以外的处理中状态禁用开始动作，不承诺中断播放。
