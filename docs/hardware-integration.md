## 3. 推荐结构：V1 低矮并排底座

第一版采用**300×240×5 mm 亚克力开放底座**：屏幕在前左，云台在前右，RK3568 水平放在后左，STM32/ST-Link 与舵机分线放在后右。这是本次建议的结构尺寸，不是厂家整机尺寸。屏幕通过 170×94×3 mm 背板、四个尼龙隔离柱和两个加强 L 角码固定到底板；云台用自身底脚安装孔独立固定到底板，不需要高立柱。屏幕与云台分别承力，适配器放机外。具体左右位置服从现有 FPC/USB 长度，不为对称而换线。

回寝室的第一轮装配目标是：所有部件固定在同一底座上，屏幕可看可触摸，摄像头能覆盖原有活动范围，线缆不会被拉紧，接口可插拔。完成这一版后再做外壳；不需要先完成外壳 CAD 才开始整合。

以下是**非比例位置草图**，英文框名避免文本图的中文宽度错位；没有整体加工尺寸、孔位或制造公差。

```text
TOP VIEW / NOT TO SCALE                 rear / connectors
 +----------------------------------------------------------+
 | [RK3568: 180 x 140]           [STM32 + ST-Link]           |
 | [raised on nylon pillars]    [servo + / GND terminals]   |
 |                                                        |
 | [screen backing + 2 L brackets]    [Pan / Tilt + camera] |
 +----------------------------------------------------------+
                 front / user       base: 300 x 240 x 5
```

- RK3568、STM32、ST-Link 和低压分配端子固定在底板上，主板垫高、背面元件/扬声器不贴底板。布局先围绕已有 FPC/USB 长度安排，不拉长总线作为默认方案。
- 屏幕固定朝前，图按 150×74 mm 横屏摆放；四孔中心距 143×67 mm。屏幕 PCB 与背板间用 15 mm 双通尼龙隔离柱，背板下部以两个约 30×30×20 mm 加强 L 角码连接底板，不夹玻璃。现有方向若为竖屏，背板与孔位整体旋转 90°并重新摆位，不改软件。排线插座留可插拔空间，必要时在背板开缺口。
- 云台固定在前右，摄像头保持现有安装方式，降低俯仰力臂。云台预留区只是摆位空间，不是实物外形；安装孔按底脚实物转印，螺栓匹配孔径和厚度。没有底脚孔则需要匹配的抱箍/夹持件，不用双面胶作为转动云台的永久固定。
- 电源适配器和舵机充电头先放整机外，内部只整理低压线；保留三路供电，暂不改为一个电源加降压模块。
- 电源插头、S1、USB Host、调试 USB、ST-Link USB/SWD 与拆装螺钉留可操作空间，先用插头实物摆位，维修不必拆下云台。
- RK3568 热源附近留通风，不把端子/线束堆在散热器上；已有风扇则保留进出风通路，不预设必须增购。
- 板载麦克风面向可收音开口；扬声器出口与麦克风口尽量分离，避免声孔被底板封住，也避开舵机和风扇振动。独立麦克风/扬声器不是本轮默认采购项。
- 增大底板支撑范围、重部件低放、外接线出口做固定；具体防倾倒能力待实物装配观察，不能凭草图计算通过。

## 5. 供电与共地图

用户本轮确认：RK3568 使用 12V，STM32 由 ST-Link 供电。舵机沿用历史独立 USB-C 取电头；标记 5V 与“实际稳定输出 5V”是不同证据。

```text
POSITIVE SUPPLIES / KEEP SEPARATE

 [RK adapter: 12V] ------> [RK DC_IN] ---> [RK board / screen / USB camera]
   rating A [U]                          existing board power paths

 [ST-Link USB source] --> [ST-Link] ----> [STM32 supply input]
   source/rating [U]       actual power pin/label [U]; keep existing wiring

 [servo charger] -------> [USB-C tap: marked 5V] --> [servo + block]
   modes/rating A [U]       actual output [unmeasured]   |         |
                                                     Pan +    Tilt +

 No positive connection between the three rows.
 No servo power from GPIO, STM32 3V3, or RK3568 3V3.

GROUNDS / EXISTING COMMON REFERENCE

 [RK GND] -- existing UART GND wire -- [STM32 GND / ST-Link GND]
                                                |
                                          common GND block
                                          /      |       \
                                 tap negative  Pan GND  Tilt GND

 Servo load return: Pan/Tilt GND -> block -> tap negative.
 Keep load current out of the UART GND / thin STM32 reference wire.
```

**供电核对结论：**

- RK3568：厂商硬件参考手册 V1.1 第 9、15–16、46–47 页规定 DC_IN 12V，并给出高负载约 12W、替换电源建议 15W 以上。这是厂商参考，不能推算当前带屏/摄像头整机余量；还缺现有适配器额定 A。不据此要求更换已在用电源。
- 该手册第 9 页的调试 Type-C 供电文字与第 22 页专门章节矛盾；第 22 页图显示 USB 电源用于 CH340C，正文明确调试口不能给主板供电。布局保留现有 12V DC_IN，不改成调试 Type-C 供电。
- STM32：继续用当前 ST-Link 供电。历史用户确认 ST-Link 3.3V 未与其他正极并联；当前具体接到 STM32 哪个电源脚仍按原线束/丝印补记，不能仅凭克隆 ST-Link 外观猜输出端。独立演示时需要安排 ST-Link 的 USB 电源来源，移除 ST-Link 或换 STM32 电源属于后续供电变更。
- 舵机：两个正极从独立舵机电源分支，两个负极回同一分配点；STM32 和 UART 保持共地。卖家极性确认、用户逐根核对和历史动作是已有证据，不反复要求重做；回寝室整理时只核对新端子/标签与旧线束一致。
- 线径按实际负载、长度、连接器额定能力和允许压降确定；当前不能给出已验证的 AWG/电流预算。舵机供电/回线优先短、牢固、截面足够，不以松散细杜邦线串接承担分配干线；信号线与其地参考合理靠近，远离扬声器/麦克风线。
- 正式装机选已有可固定的分配端子/可靠分线接头，每个端口按其允许线数连接，不把多根线硬塞进单线孔。裸露导体绝缘、接头标记 +/GND/轴名；使用端子标记与原线束证据，不能仅凭线色确认极性。
- 端子固定在底板、入口线夹/扎带固定外被、给接头留维修余量，不拉扯芯线/排针。不让运动线承受固定端子重量；接线图与端子标记一致，能单独拆下每一轴。

用户无万用表：当前无法测得舵机/STM32 实际电压、负载压降、瞬态电流、共地电位差或电源裕量。后续目视“无抖动/未重启”只能作为装配观察，不替代电气测量；这不阻挡断电布局与固定工作。

## 7. 活动余量、干涉与材料

- 摄像头 USB 在 Pan 和 Tilt 两处分别留活动弯/松弛段，固定侧与移动侧各做适当应力释放；不能扎死整个活动段，也不能垂入舵盘/支架夹缝。弯曲量和线长由实际运动包络决定，不能先给任意厘米数。
- Tilt 只带现有摄像头及必要支架；线缆拉力也属于负载。尽量让摄像头重心靠近转轴，不在相机端悬挂转接头。停止 PWM/断电可能因重力下垂，既有 OFF 回执不证明负载被锁住；装配观察时关注屏幕/支架是否被碰到。
- 机械干涉检查覆盖已使用范围和双轴组合位置；保持现有云台/舵盘方向。若仅迁移底座且无包络变化，复用原限位；若支架/线缆使范围变窄，先停止并记录可用空间，再安排针对性处理，不现场扩限位。
- 防倾倒重点看屏幕支架、云台和外接 USB/电源线拉力；线夹固定到低处，适配器外置，必要时才增加低处配重或底板宽度。先摆位核对，不凭尺寸表宣称稳定。
- 热源上方不被线束覆盖，散热出口不直吹麦克风；最终封壳后温升和音频体验是新增装配条件，不能由开放底板历史结果代替。

## 8. 装配顺序与最小验证

1. **课上确定方案（本轮）**：设备已经齐全，只是暂时不在手边；完成资料审查、官方尺寸查找、三张关系/布局图、线束表和装配安排。最终加工孔位留到实物摆位时确定。
2. **准备材料与孔位**：按第 3.1 节准备结构材料。回寝室断开全部电源和 USB 供电，先接原 FPC 确定屏幕位置，再按第 3 节摆放各部件及未供电插头；描下真实安装孔并标正反面，交加工店切板、去毛刺和打孔。此时不拆舵盘、不裁线、不上电。
3. **安装机械结构**：底板先装脚垫和尼龙支柱，再锁主板。角码锁住屏幕背板，屏幕通过四个尼龙隔离柱锁到背板；云台用底脚匹配固定件锁在右前方。安装 STM32 绝缘支座、ST-Link 和分配端子，确保排针/焊点/背面器件不受压。
4. **整理线束**：按 S/P/G 标签记录原线去向，固定分配点，将临时汇接整理为可拆装端子/线束；逐个接头与旧关系对照，补绝缘和应力释放。三路正极继续隔离。缺少任何关键极性/电源档位依据时先完成不受影响的机械固定。
5. **一次必要装配检查（后续现场安排）**：铭牌/供电端序等必要信息齐备后，保持现有固件和受控应用，在有人观察时检查启动后预览/双轴 OFF；用现有操作覆盖安装所需活动范围并停止/退出，一次观察新线束是否拉紧、USB 掉线、机械碰撞、Tilt 下坠、底板倾斜、异常噪声/发热或主板重启。出现异常就停止并断开对应电源，不把无异常写成电气裕量通过。本轮不执行这一步。
6. **定外壳**：记录实际占地/高度、各插头包络、活动余量及固定点，再决定整机外壳与散热/声孔。封壳造成的新热/声学/维修问题只补对应检查，不重跑全部基础硬件验收。

复用已完成的 UART9 boot、PC13、UVC、双轴方向/边界与停止记录，不安排重复烧录、逐档扩角或压力测试。改变了什么才验证什么：新电源/延长供电线对应电气条件，新支架/云台负载对应干涉与 Tilt 行为，新 USB 拓扑对应枚举/取流，封壳对应散热/音频。真实供电量化仍需测量能力；本页不要求因此停止全部装配规划。
