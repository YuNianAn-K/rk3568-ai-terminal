## 贯穿边界与可选工作

- 物理动作走白名单、参数限幅、回执与超时；已实现的 PAN/TILT/TRK 以当前固件、[云台 README](../apps/qt-ui/gimbal-joystick/README.md) 与最新验收为准。早期 [UART 文档](uart-protocol-draft.md)保留基础 LED 与二进制草案背景，不能代替最新跟踪实现范围。
- 各阶段记录停止按钮/命令、目标丢失、摄像头故障、串口失联、CPU/内存/温度与固件/配置回退。历史 UART9 boot 备份和脚本见 [HANDOFF](../HANDOFF.md)。
- 离线语音偶发拒识、未覆盖的网络故障、历史凭据迁移/轮换和部署清单可并行处理；不重复已通过的短测，也不宣称完全稳定。
- 中文 KWS、“寻找水瓶”、连续对话与 MQTT/ESP8266 业务均属后续或可选扩展，不阻挡基础人物跟踪闭环；不规划新开发板、大量传感器或机器人底盘。
