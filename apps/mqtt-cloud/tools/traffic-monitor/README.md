# ECS 流量与费用小窗口

本机按需启动的只读监控，沿用用户桌面DeepSeek余额卡片的浏览器小窗口方式。源码在本目录，
无凭据机器配置/SDK在忽略目录`local/ecs-monitor/`；不修改已有DeepSeek页面。
无云端写操作，不需要服务器SSH，不连接RK3568/VM，不创建周期自动化或开机启动。

## 使用

桌面双击`ECS 流量监控`快捷方式，或运行`start.ps1`。它打开Edge独立小窗口，仅监听本机
`127.0.0.1:8796`，没有局域网或公网入口。端口被其他程序占用时退出，不接管/停止其他程序。
再次运行只复用精确脚本/PID匹配的本次程序。点击“停止并退出”结束本机采集；直接关闭所有页面后，
无页面心跳120秒自动退出。不影响ECS服务，电脑关机后没有监控或流量保护。

初始“待接入”是真实限制；不会沿用Edge登录Cookie、读取浏览器凭据或伪造实时数据。
2026-10-19控制台核验的“深圳0.0008GB、ECS已升级CDT、账单暂无记录”仅放在历史记录中，
跨月自动失效，不作为动态计量，也不表述为最终零费用。

用户取得专用RAM只读身份后，在窗口“接入只读凭据”输入AccessKey ID/Secret；可填STS临时Token。
点击“加密保存并连接”后，以Windows当前用户的DPAPI加密保存到忽略目录
`local/ecs-monitor/credentials.dpapi`。以后双击桌面入口自动解密并连接，无需反复填写；
关闭页面、停止程序、正常重启电脑不会清除此密文。只在本机进程内解密，不存浏览器storage、
明文配置或日志，不发到聊天。不使用主账号密钥。

点击“忘记本机凭据并断开”删除本方案的密文并释放当前连接；不撤销云端AccessKey。
若选“仅本次连接”，本次不保存，且会清除本方案以前记住的凭据，避免下次意外使用旧身份。
STS临时令牌仅允许本次连接。首次升级前仅存内存的密钥无法恢复，需要用户最后输入保存一次。
若旧Secret未另存且创建结果页已关闭，需要用户自行新建轮转密钥；创建结果页保持打开，
先在监控里加密保存、确认真实数据及重启自动接入成功，再关闭结果页并停用旧密钥。
密文绑定目标实例及公网IP；换Windows身份/系统、损坏文件或更换目标时，失败会明确提示重新接入，
不会回退为明文保存。Windows同一用户下的恶意程序仍可能访问该用户可解锁的数据，系统加密不等于隔离同用户进程。
窗口仅发起两个官方HTTPS读取接口：

- 云监控`DescribeMetricList`（2019-01-01），RAM操作为`cms:QueryMetricList`。
- 费用`DescribeInstanceBill`（2017-12-14），RAM操作为`bssapi:DescribeInstanceBill`，产品限制`cdt`。

`readonly-policy.json`是本方案的最小策略；两接口不支持实例级资源授权，因此监控读取范围是账号级，
程序只查询配置中的目标公网IP/实例。账单权限通过`bssapi:ProductCode=cdt`约束；不授予停机、网络、
RAM、创建资源、支付等写权限。

## 数据含义

- 入站/出站速度：公网IP指标`VPC_PublicIP_InternetInRate/OutRate`，单位bit/s，60秒采集粒度。
  超过180秒不再显示为当前速度。获取失败保留旧累计数并明确提示，绝不把失败变成0。
- 今日/本月出站：按已收到的60秒平均速率积分，bit除8后换算十进制GB；首次最多32页/方向读取月内样本，
  之后每60秒重叠5分钟更新、按时间戳去重。时区固定UTC+8，跨月清空。未报告/实例创建前的区间均未知，
  不插值、不补零；页面列出覆盖时长。监控估算不等于CDT计费口径或账号额度余额。
- CDT已出账应付：每15分钟查询，完整读完分页，仅合计精确匹配目标实例且币种CNY的CDT行。
  空账单、账号级合并行或其他实例都不冒充本实例0元；页面提示无法归属。数据本身约延迟24小时。
- 20GB是中国内地账号共享免费额度，不是本实例硬上限；本机观测告警10/15/18GB仅是页面分级提醒。
  其他内地资源也可能消耗额度。价格模型仅适用于已确认的普通BGP/CDT第一阶梯，不自动更改计费方式。

## 20GB自动停止的边界与推荐

CDT官方功能为计费出账，未提供月额度硬断网开关。费用预算只提醒，不能当作扣费上限。
本机窗口断线/关机不能保护服务器，因此**当前保护未启用**，程序中没有云端停机/改防火墙接口。

推荐下一阶段在ECS独立实现：持久保存公网出站保守计数，与官方累计数据核对；预留2GB余量，
18GB触发停止对外MQTT/API业务；重启保持触发状态，不自动恢复。计数缺口/重置、其他账号资源、
监控延迟均需告警；以已知用量重新校准后才开启保护，不能从安装时0字节冒充月初0字节。
SSH22、系统必要通信单独处理，不能通过停止全部网络把管理入口锁死。
**保留SSH及系统通信意味着仍有出站流量，不能承诺绝对零扣费。**
若用户要求所有公网流量到量即断，需要另行批准关闭公网带宽/停止实例的方式，并先验证Workbench/
串行控制台等恢复入口；不能在保护动作中保留公网SSH却声称总出网为零。
服务器SSH已由用户新连接验收，管理来源已收紧；后续保护仍需先核对业务与主机规则才能确定精确动作。
部署前备份规则和计数，创建本方案独立规则/服务并测试回退；失败只停止/撤销本方案，不关闭UFW或改变22。
监控程序不部署保护、不修改安全组/防火墙、不停止云端服务或签发凭据；管理入口维护记录另存于本机忽略目录。
