## 使用

上方保持相机画面与人物框，中间显示视觉状态、控制器状态和人物提示。
下方语音区始终显示唤醒/按键入口、聆听/识别/处理状态，以及 ASR 与回复/执行回执。
“对话”和“执行状态”是同一窗口中的显示切换，不创建独立窗口，不销毁任务对象。
长识别内容与回复可在对话区上下滚动。手动点动可展开/收起，同时语音区继续存在。
“立即停止”固定在底部，语音等待或 LLM 处理期间也可执行。

人物 START 仍要求前台窗口、就绪相机、已初始化位置、选中且新鲜的目标和互斥模式。
不自动回中位、选多人目标或开始跟随。STOP 使用既有独立本地控制路径，硬件双轴 OFF 不依赖普通问答结束。
真实窗口隐藏、失焦、关闭、相机故障仍停止检测/跟随；退出释放相机和 UART 锁。
此轮没有添加桌面退出后继续跟随的能力。

## 浅色玻璃候选（2026-10-14）

按浅色设计图调整为珍珠白底、半透明渐变卡片、细边与轻阴影，蓝色为选中状态，红色仅用于独立停止入口。
材质采用静态分层，不添加实时视频背景模糊，也不更改检测模型、相机处理或跟随控制。
相机预览由 PreviewItem 的可选 `cornerRadius` 裁剪圆角，默认值为 0，保持其他调用方原矩形行为。
浮动视觉工具条、常驻语音区及可展开手动区只改变呈现，原位置确认、目标新鲜度、互斥和失焦停止条件保持。
语音区的波形为装饰，并非实时音量计；真实状态文字仍来自 VoiceBridge。

`tests/render_person_ui.py` 继续验证实际 QML 的目标保护、面板切换、长回复、独立停止和隐藏/恢复行为。
`tests/previewitem_test.pro` 用同一 Qt5 SDK 构建原生圆角绘制 fixture：检查画面中心不变、默认矩形及圆角透明边界。
该 fixture 不打开相机、不连接 UART；模拟截图不代表真实板端画面。
浅色阶段候选仅在 `/tmp/ui-glass-light-20261014/app` 预览，当时正式应用与原深色候选未替换。
